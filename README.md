# Jan Dristi - Civic Issue Tracking System 

Jan Dristi is a civic issue reporting web application where users can report local problems, track issue status, earn badges, and submit feedback.

## Features

- User sign up and sign in
- Report civic issues with photo, category, address, and location
- Track submitted issues
- Status updates for issues
- Badge system: Bronze, Silver, and Gold
- Feedback and rating system
- Clean responsive UI

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI
- LocalStorage for demo data
